# 雅思考生在线考试系统 - 面试技术文档

## 一、项目概述

### 1.1 项目背景

面向雅思考生的在线考试系统，支持多题型作答、听力音频播放、在线交卷，对**数据可靠性**和**播放稳定性**有极高要求。

### 1.2 核心挑战

| 挑战 | 问题 | 解决方案 |
|------|------|---------|
| 网络波动 | 答案易丢失，提交成功率仅 75% | 本地缓存 + 网络探测 + 指数退避重试 |
| 弱网上传 | 口语音频大，上传易中断 | 切片上传 + 断点续传 |
| 音频播放 | 全量加载慢，卡顿频繁 | HTTP Range 流式预加载 |
| 题型扩展 | 7种题型各自独立开发，复用性差 | 策略模式 + 动态组件按需加载 |

### 4.2 答案提交机制

**文件：** `src/utils/browser/submitAnswer.ts`

**核心策略：本地缓存 + 网络探测 + 指数退避重试**

```typescript
// 答案提交数据结构
interface StudentSubmitAnswer {
  answerItems: AnswerItem[];
  doTime: number;
  id: number;
  type: 'LISTENING' | 'READING' | 'WRITING';
}

// 提交答案核心逻辑
const submitStudentAnswer = async (answer: AnswerItem) => {
  // 1. 先存本地 LocalStorage
  saveToLocalStorage(answer);

  // 2. 探测网络状态
  if (!await checkNetwork()) {
    // 网络不可用，等待恢复后重试
    await waitForNetwork();
  }

  // 3. 指数退避重试
  let retries = 0;
  const maxRetries = 5;

  while (retries < maxRetries) {
    try {
      await judgingProblem(answer);
      removeFromLocalStorage(answer.id); // 提交成功，移除本地缓存
      return;
    } catch (error) {
      retries++;
      const delay = Math.pow(2, retries) * 1000; // 1s, 2s, 4s, 8s, 16s
      await sleep(delay);
    }
  }
};
```

**成功率提升路径：**

| 阶段 | 成功率 | 改进 |
|------|--------|------|
| 原始 | 75% | 无缓存无重试 |
| +本地缓存 | 85% | 离线持久化 |
| +网络探测 | 90% | 等待恢复 |

### 4.3 切片上传与断点续传

**场景：** 口语音频文件大（通常 10MB+），弱网上传易中断

**文件：** `src/utils/browser/submitAnswer.ts`

```typescript
// 切片配置
const CHUNK_SIZE = 1024 * 1024; // 1MB per chunk
const CONCURRENT_UPLOADS = 3;    // 并发数

interface ChunkUploadState {
  fileId: string;       // 文件唯一标识
  chunks: Chunk[];      // 切片列表
  uploadedChunks: Set<number>; // 已上传切片索引
  progress: number;      // 总进度
}

// 切片上传
const uploadInChunks = async (file: File, onProgress?: (p: number) => void) => {
  const fileId = generateFileId(file); // 哈希或UUID
  const chunks = createChunks(file, CHUNK_SIZE);
  const state: ChunkUploadState = {
    fileId,
    chunks,
    uploadedChunks: new Set(),
    progress: 0
  };

  // 读取本地记录，断点续传
  const savedState = getLocalUploadState(fileId);
  if (savedState) {
    state.uploadedChunks = new Set(savedState.uploadedChunks);
  }

  // 并发上传未完成切片
  const pendingChunks = chunks.filter((_, i) => !state.uploadedChunks.has(i));

  await Promise.all(
    pendingChunks.map(chunk =>
      uploadSingleChunk(chunk, state)
    )
  );

  // 所有切片完成，通知服务器合并
  await mergeChunks(fileId);
};

// 单切片上传 + 断点记录
const uploadSingleChunk = async (chunk: Chunk, state: ChunkUploadState) => {
  try {
    await upload(chunk);
    state.uploadedChunks.add(chunk.index);
    saveLocalUploadState(state); // 保存进度到 LocalStorage
    updateProgress(state, onProgress);
  } catch (error) {
    // 失败不删除已上传记录，支持断点续传
    throw error;
  }
};
```

### 4.4 HTTP Range 流式预加载

**文件：** `src/stores/exam.ts`

```typescript
// 获取听力音频地址
getListenAudioSrc(): string {
  // 优先使用直接的 audioFileUrl
  if (this.listenAudio) return this.listenAudio;
  if (this.paperId === 0) return "";
  return getStreamAudioUrl(this.paperId);
}

// 探测音频是否支持 Range
async checkListenStreamAvailable(paperId: number): Promise<boolean> {
  const url = getStreamAudioUrl(paperId);
  const res = await fetch(url, { headers: { Range: "bytes=0-0" } });
  return res.ok || res.status === 206; // 206 = Partial Content
}
```

## 七、可靠性保障

### 7.1 答案不丢失机制

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   作答 → LocalStorage ────────────────────────┐   │
│       ↓                                          │   │
│   尝试提交 ─────────────────────────┐          │   │
│       ↓                                ↓          │   │
│   成功 ─→ 清除本地缓存           失败 ─→ 重试    │   │
│                                            ↓          │   │
│                              指数退避 (1s,2s,4s,8s)  │   │
│                                            ↓          │   │
│                                    网络恢复 ──→ 提交 │   │
│                                                     │   │
└─────────────────────────────────────────────────────┘
```

### 7.2 断点续传

```
上传文件 ──→ 切片(1MB) ──→ 并发上传(3个切片)
                ↓
            保存进度到 LocalStorage
                ↓
            中断(网络波动)
                ↓
            恢复 ──→ 读取本地进度 ──→ 跳过已上传切片
```

## 十、面试高频问题

### Q1: 如何保证答案不丢失？

**参考答案：**
> 三层保障：1) 作答时同时写入 LocalStorage 2) 网络异常时自动重试 3) 使用指数退避算法避免拥塞。离线答案持久化，网络恢复后自动上传，成功率从 75% 提升到 95%。

### Q2: 弱网下大文件如何上传？

**参考答案：**
> 采用切片上传 + 断点续传。将文件按 1MB 分片，并发上传 3 个切片，每个切片完成后记录进度到 LocalStorage。中断后恢复时读取本地进度，跳过已上传切片，继续上传剩余部分。

### Q3: 多种题型如何设计？

**参考答案：**
> 使用策略模式。将每种题型封装为独立组件，通过 type 字段动态选择。新增题型只需实现组件并注册到策略表，接入成本从 2 人天降至 0.5 人天。

### Q4: 音频播放卡顿如何优化？

**参考答案：**
> 基于 HTTP Range 实现流式预加载。使用 HTML5 Audio 的 preload + Range 请求，边缓冲边播放。配合 Promise 缓存避免重复探测，卡顿率降低 40%。

### Q5: 考试系统最重要的是什么？

**参考答案：**
> **数据可靠性**。考试涉及考生利益，答案不能丢失。对比功能炫技，我们更关注：离线缓存、网络探测、指数退避、事务性提交。
